DungeonKit

A free trainer and companion app for Minecraft Dungeons and Minecraft Dungeons II. It reads and edits the game's own memory live while you play - the same idea as a Cheat Engine table, packaged into a proper app. No Cheat Engine needed.

What it does

DungeonKit connects to your running game and lets you flip switches, edit values and watch live stats - currencies, difficulty, item stats, player tools, a free camera, an on-screen overlay and more - without touching your save files directly or needing a second tool running alongside it.

It auto-detects which game and build you're running (Steam, Microsoft Store/Xbox App, or the Minecraft Launcher) and adapts the feature list to match.

What's inside

Features

Full feature breakdown for both games. See the Changelog on GitHub for the complete version history.

Minecraft Dungeons

  • Infinite Arrows, Infinite Lives, No Cooldown, Infinite Enchant Points
  • Currency editing (Emeralds, Gold, Ender Eyes) and XP multiplier / total XP
  • Threat/Apocalypse Level editing
  • Position save/teleport, plus a Teleports page for every mission and area
  • No Clip & Fly, God Mode, live Player Stats
  • Full Item Editor - item ID, power, rarity, gilded status, enchants + tiers, stats, copy/load item
  • Merchant price editing, Camera Editor with Photo Mode, console command access

Minecraft Dungeons II

  • Player tools - God Mode, No Clip, Overkill control, No Cooldown, Infinite Arrows/Enchant Points, difficulty lock-in, enemies-ignore-you mode
  • Inventory Viewer & Editor - power, rarity, level, stack, rerolls, gilded properties, plus an Enchants editor (which enchant, tier, point cost)
  • World tools - jump to any mission/area, live quest tracking, waypoints
  • Nearby Viewer - nearby chests/enemies with distance, auto-rescan
  • Item rarity drop tuning
  • Camera & Display - free camera, on-screen overlay with toggleable live stats
  • Console command access, merchant price editing

App-wide

  • Full theming - color presets plus custom QSS/CSS import
  • Reorderable sidebar, multi-language UI (EN/ES/FR/JA/ZH/RU)
  • Quick Access shortcuts (Pak folder, save backups, modding sites)
  • Live status indicator so you always know what's expected to work on your build
  • Checks GitHub for a newer release on startup - never installs anything on its own

Build it yourself

Install Qt 6 (or Qt 5.15+), Visual Studio 2022 (or MinGW) and CMake, then either run Build-DungeonKit.bat from the project folder, or:

cmake -S . -B build -DCMAKE_PREFIX_PATH="C:/Qt/6.7.0/msvc2019_64"
cmake --build build --config Release

Full build and usage steps are in the repository's README. Click a command above to copy it.

Built with

Most of it works through Unreal Engine's own reflection system - reading property offsets by name at runtime instead of hardcoding memory addresses, so it holds up better across game updates than a typical fixed-offset trainer.
